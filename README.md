# E-KLIK_Knowledge-and-Location-Information-Kiosk
The Knowledge and Location Information Kiosk (E-KLIK) is a specialized, web-based 3D campus navigation and intelligent information terminal designed exclusively for the Eastern Visayas State University - Ormoc City Campus (EVSU-OCC). E-KLIK serves as an interactive digital directory and AI-driven assistant to resolve localized campus navigation and administrative bottlenecks. It features a draggable 3D campus map for visual spatial orientation, coupled with a Retrieval-Augmented Generation (RAG) conversational AI to instantly answer campus-specific inquiries. Using Machine Learning clustering, the system autonomously analyzes search logs to predict and display trending student questions. The platform is powered by a Python (FastAPI) backend and a MySQL database, with a frontend built on HTML, CSS, JavaScript, and lightweight 3D web rendering tools
